# PilotDeck — AI Agent Case Showcase

PilotDeck 是一个以 WorkSpace 为核心的面向生产力的智能体开源平台。用户只需用自然语言描述需求，AI Agent 自主完成从方案设计到代码交付的全流程。

以下案例均来自真实使用场景。

---

## 核心能力

<Tabs>
  <Tab title="WorkSpace 隔离">
    每个项目拥有独立的文件系统、记忆存储和技能集，并行工作互不干扰。
    <Frame>
      <img src="/showcase/assets/workspace_en.gif" alt="WorkSpace 隔离演示" />
    </Frame>
  </Tab>
  <Tab title="白盒记忆">
    记忆的生成、提取、存储和检索全程可见。当 AI 记错时，可以精准定位并修复问题条目。
    <Frame>
      <img src="/showcase/assets/memory_en.gif" alt="白盒记忆演示" />
    </Frame>
  </Tab>
  <Tab title="智能路由">
    自动检测任务难度，复杂调用走旗舰模型，简单调用走轻量模型，大幅降低 token 开销。
    <Frame>
      <img src="/showcase/assets/router.gif" alt="智能路由演示" />
    </Frame>
  </Tab>
  <Tab title="持续运行">
    离开键盘后 Agent 持续发现待办任务、运行长期监控，最终将交付物落地为本地文件。
    <Frame>
      <img src="/showcase/assets/awo_en.gif" alt="持续运行演示" />
    </Frame>
  </Tab>
</Tabs>
