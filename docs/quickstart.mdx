# 快速开始

## 基础界面介绍

进入 PilotDeck 后，你会看到项目、会话、模型、记忆、技能等入口。整体交互围绕 WorkSpace 展开：每个项目拥有独立上下文，适合并行推进不同任务。

<img className="quickstartImage" src="/pilotdeck.github.io/img/docs/quickstart/quickstart-02.gif" alt="PilotDeck 快速开始入口" />

## Workspace 项目与 Plan 模式

WorkSpace 是 PilotDeck 的核心组织方式。你可以把每个真实项目都放在独立 WorkSpace 中，让文件、记忆、技能和会话记录保持隔离。

Plan 模式适合较复杂的任务。Agent 会先拆解目标、生成计划，再逐步执行。这样可以避免一上来就直接修改或运行任务，也方便你在关键节点确认方向。

## Always-on 常驻

Always-on 用来处理需要长期运行或定时触发的任务，例如定时检查、持续跟踪、定期生成报告等。

- 你可以创建 cron job 定时任务。
- Agent 也可能基于上下文自主发现后续待办。
- 常驻任务会尽量把结果沉淀为可追踪的会话和文件。

<img className="quickstartImage" src="/pilotdeck.github.io/img/docs/quickstart/quickstart-04.png" alt="Always-on 常驻任务" />

## Memory 记忆

Memory 会定时记录有长期价值的内容，例如用户偏好、项目背景、常用路径、关键决策等。

和黑盒记忆不同，PilotDeck 更强调可见、可查、可编辑。你可以查看记忆来源，也可以根据需要修正不准确的记录。

<img className="quickstartImage" src="/pilotdeck.github.io/img/docs/quickstart/quickstart-05.png" alt="Memory 记忆界面" />

## Routing 省钱路由

Routing 用来根据任务难度选择合适模型。简单任务可以走轻量模型，复杂任务再切换到更强模型，从而降低整体成本。

<img className="quickstartImage" src="/pilotdeck.github.io/img/docs/quickstart/quickstart-06.png" alt="Routing 省钱路由" />

## Skill 技能

Skill 是 PilotDeck 的能力扩展机制。你可以把常用工作流、工具调用、平台操作或项目规范封装为技能，让 Agent 在合适场景下自动调用。

<img className="quickstartImage" src="/pilotdeck.github.io/img/docs/quickstart/quickstart-07.png" alt="Skill 技能入口" />

技能可以帮助 Agent 理解特定任务应该如何执行，例如文档处理、平台操作、项目构建、发布前检查等。

<img className="quickstartImage" src="/pilotdeck.github.io/img/docs/quickstart/quickstart-08.png" alt="Skill 技能列表" />

当技能被触发时，Agent 会根据技能说明执行更稳定、更结构化的流程。

<img className="quickstartImage" src="/pilotdeck.github.io/img/docs/quickstart/quickstart-09.png" alt="Skill 技能使用示例" />

## 设置

设置页可以管理模型、路由和其他系统选项。

<img className="quickstartImage" src="/pilotdeck.github.io/img/docs/quickstart/quickstart-10.png" alt="PilotDeck 设置页" />

### 添加提供商

**设置** → **服务配置** → **模型池** → **添加提供商** → **选择供应商** → **填入 API Key、URL 等** → **保存并重载**

<img className="quickstartImage" src="/pilotdeck.github.io/img/docs/quickstart/quickstart-setting-provider.gif" alt="添加提供商" />

### 设置/更改主模型

**设置** → **服务配置** → **智能体** → **主智能体模型** → **选择** → **保存并重载**

<img className="quickstartImage" src="/pilotdeck.github.io/img/docs/quickstart/quickstart-setting-agent.gif" alt="设置/更改主模型" />

### 设置省钱路由

省钱路由的目标是让系统按任务难度自动选择模型，并用统一价格表估算成本。配置后，你可以更清楚地看到哪个模型花钱多、路由是否真的省钱。

**设置** → **服务配置** → **路由** → **自行选择你的模型配置** → **保存并重载**

<img className="quickstartImage" src="/pilotdeck.github.io/img/docs/quickstart/quickstart-setting-router.gif" alt="设置省钱路由" />
