# PilotDeck — AI Agent Case Showcase

PilotDeck is a workspace-centric, productivity-oriented open-source AI agent platform. Simply describe your requirements in natural language, and the AI Agent autonomously handles the entire workflow from solution design to code delivery.

All cases below come from real-world usage scenarios.

---

## Core Capabilities

<Tabs>
  <Tab title="WorkSpace Isolation">
    Each project has its own file system, memory store, and skill set — parallel tasks never interfere.
    <Frame>
      <img src={useBaseUrl('/showcase/assets/workspace_en.gif')} alt="WorkSpace isolation demo" />
    </Frame>
  </Tab>
  <Tab title="White-Box Memory">
    Memory generation, retrieval, storage, and search are fully transparent. When AI remembers incorrectly, you can pinpoint and fix the problematic entry.
    <Frame>
      <img src={useBaseUrl('/showcase/assets/memory_en.gif')} alt="White-box memory demo" />
    </Frame>
  </Tab>
  <Tab title="Smart Routing">
    Automatically detects task difficulty — complex calls go to flagship models, simple calls go to lightweight models, drastically reducing token costs.
    <Frame>
      <img src={useBaseUrl('/showcase/assets/router.gif')} alt="Smart routing demo" />
    </Frame>
  </Tab>
  <Tab title="Always-On">
    After you step away, the Agent keeps discovering pending tasks, running long-term monitors, and saving deliverables as local files.
    <Frame>
      <img src={useBaseUrl('/showcase/assets/awo_en.gif')} alt="Always-on demo" />
    </Frame>
  </Tab>
</Tabs>
