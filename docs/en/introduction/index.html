PilotDeck

PilotDeck is a WorkSpace-first open-source AI agent platform built for productivity.

It is not just another chat-style AI tool. PilotDeck starts from the WorkSpace: each project gets its own operating deck, with white-box memory inside the deck, intelligent routing across decks, and Always On automation outside the deck. It turns AI agents from conversation toys into tools that actually move work forward.

Core Capabilities​

WorkSpace

One deck per project: dedicated files, memory, and skills, with clean isolation across parallel projects

Cost-Saving Router

TokenSaver tiering plus multi-provider fallback for lower cost and higher availability

Long-Term Memory

Project Memory and Feedback Memory with traceable, white-box behavior

Always On

Deploy once and let PilotDeck keep moving: Discovery plus Cron-based scheduled work

Gateway

WebSocket and HTTP gateway for CLI, Web, Desktop, and Feishu channels
