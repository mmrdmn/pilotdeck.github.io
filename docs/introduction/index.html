PilotDeck

PilotDeck 是一个以 WorkSpace 为核心的面向生产力的智能体开源平台。

它不是又一个"能聊天的 AI 工具"——PilotDeck 的架构从 WorkSpace 开始：每个项目一个舱，舱内白盒记忆、跨舱智能路由、舱外 Always-on 主动推进。让 AI Agent 从"对话玩具"变成真正干活的生产力工具。

核心能力​

WorkSpace 工作舱

每个项目一个舱——专属文件、专属记忆、专属技能，多项目并行互不干扰

省钱路由 (Router)

TokenSaver 智能降档 + 多 Provider Fallback 容错

长期记忆 (Memory)

Project Memory + Feedback Memory 双层记忆，全链路白盒可追溯

后台常驻 (Always On)

你部署，我推进——Discovery 主动发现 + Cron 定时任务

消息网关 (Gateway)

WebSocket + HTTP 双协议网关，CLI / Web / 桌面 / 飞书统一接入
